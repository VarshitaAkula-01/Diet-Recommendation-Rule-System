# 🥗 NutriGuide – Diet Recommendation Rule System

## 📌 About the Project
NutriGuide is a rule-based expert system that provides personalized meal recommendations based on the user's dietary preferences. It helps users explore suitable meal options through a simple and user-friendly web interface.

## 🎯 Objectives
- Recommend meals according to dietary preferences.
- Support Vegetarian, Non-Vegetarian, and Vegan meal options.
- Display meal suggestions with relevant food images.
- Provide a simple and interactive user experience.

## ✨ Features
- 🥦 Vegetarian meal recommendations
- 🍗 Non-Vegetarian meal recommendations
- 🌱 Vegan meal recommendations
- 🍽️ Meal cards with food images
- 📅 Weekly meal plan with rotating suggestions
- 📱 Responsive and user-friendly interface

## 🛠️ Technologies Used
- React.js
- JavaScript
- HTML5
- CSS3
- Vite

## ⚙️ How It Works
1. The user selects a dietary preference.
2. The rule-based system matches the selection with predefined meal rules.
3. Suitable meal recommendations are displayed.
4. Users can explore meal options and weekly suggestions.

## 🚀 Getting Started

### Prerequisites
- Node.js and npm installed

### Installation
1. Clone the repository:
   ```bash
   git clone YOUR_REPOSITORY_URL
   ```
2. Navigate to the frontend directory:
   ```bash
   cd Diet-Recommendation-Rule-System/frontend
   ```
3. Install dependencies:
   ```bash
   npm install
   ```
4. Start the development server:
   ```bash
   npm run dev
   ```

5. Open the local URL displayed in your terminal.
